# 本机角色卡的模型接口

角色卡只保留一个「设置」入口，分为「角色设定」和「模型连接」。模型 API 默认显示服务商、API Key 和模型，其他连接参数放在高级设置；支持读取账号可用模型，失败时保留手工填写。也可选择使用本机已登录的 Codex。

## 部署条件

- API 服务和包含内置 `api` 引擎的 Cumora daemon 由同一本机用户运行，共用 `~/.cumora`。当前 Windows 桌面部署中，这部分在 WSL 的 Cumora 发行版内运行。
- API 服务环境设置 `CUMORA_ROLE_CONNECTIONS=1`。默认关闭，不把本机密钥管理暴露给其他托管部署。
- 本机配对文件 `~/.cumora/computer.json` 决定运行宿主；它所属工作区的 owner/admin 才能管理接口。角色和宿主都必须属于该工作区。
- 同步安装本版本的 daemon bundle，旧版本无法读取角色接口保险库。
- ChatGPT 原有 Codex 登录保持独立。用户主动选择「模型 API」并保存后，该角色会转到本机 API 运行宿主，按服务商 API 用量计费。

## 直接调用与兼容范围

- API 角色使用内置 DirectApiAdapter，直接向服务商发送 Anthropic Messages 或 OpenAI Chat Completions 请求，不启动 Claude Code 或其他模型 CLI，不使用本地协议桥转发。
- 沿用现有群聊调度、人格、相处记忆、附件和每次模型调用的用量记账，调用来源为 byoa-api。普通模型 completion 文本不直接发送到聊天，发言通过受鉴权的 Cumora 会话工具进行。
- 只开放消息阅读、回复、反应和相处记忆等会话工具。模型不能执行 shell、读取任意本机文件或改用其他角色身份；本机 Codex 的原有能力保持不变。
- 每轮最多 10 次模型调用，同一轮相同的已成功回复去重；遇到群聊 HELD 时仍允许重新判断后再提交。每轮从当前上下文开始，不复用旧模型会话。
- 支持已在角色目录中缓存的图片，最多 6 张、单张 10 MB、总计 20 MB；是否可理解图像仍取决于所选模型。音频、供应商专有工具、Responses-only 模型和原生逐 token 转发暂不支持。
- 修改连接使用「测试并保存」，验证主模型和不同的快速模型后才生成并应用新版本。测试会产生少量 API 用量，不发送群聊消息。仅修改角色资料不重复测试连接。
- 读取模型列表不等于模型有调用权限，最后仍以测试调用为准。部分兼容接口不提供列表时可手填模型 ID。
- HTTPS、DNS 固定、公网地址检查、禁止重定向、响应大小和超时限制同时适用于直连和连接测试。

## 密钥与一致性

- 新保存的接口配置位于 `~/.cumora/role-connections.enc`，使用 AES-256-GCM；独立随机加密密钥位于 `role-connections.key`，两个文件仅本机运行用户可读写。二者不可放进项目源码、角色提示词或智能体工作目录。
- 这属于静态文件加密，不防御能同时读取保险库与加密密钥的本机管理员。
- 普通接口响应只包含地址、模型和 `hasKey`，不返回密钥。留空保留原密钥；修改地址、协议或认证方式必须重新填写。
- 旧 `providers.json` 保持兼容，不自动删除它或旧备份；其中已有密钥仍受原文件权限保护。
- 配置先生成不可变版本，再通过现有角色分配接口切换。表单保存失败时，正在运行的角色仍保留旧版本。一个角色的修改不覆盖其他角色的凭据。
- 每个角色编辑器打开时读取版本号；旧页面提交过期配置会收到冲突提示。未绑定的旧配置在后续保存时经过一天保留期后清理。
- 当前上限为 50 个保险库配置版本；备份和迁移需要同时保留保险库文件与其加密密钥，并重新完成目标电脑配对，不能只复制桌面快捷方式。

## 验证

类型检查：`npm run server:typecheck`、`npm run typecheck`。

单元测试：`server/src/__tests__/direct-api-engine.test.ts`、`server/src/__tests__/role-connections.test.ts` 及现有 provider profile 测试。

隔离数据库集成测试：`server/src/__integration__/role-connections.test.ts`。必须使用专用、名称含 `test` 的数据库；测试会清空测试表，不能指向正式数据库。

本机实施验证已覆盖 DeepSeek 的 Anthropic / OpenAI 兼容端点的真实工具调用。OpenCode Haiku 在 2026-11-13 验证时模型列表可见，但消息端点返回 HTTP 403 `Endpoint is unavailable`，这不是本地软件可以修复的服务商故障或账号限制。
